## Commits

1. `23fdd16` — **Gate the node log feed in `/api/events` in open mode (M2 follow-up).**
   `auth.openEventsFromNetwork` / `BLOCKYARD_OPEN_EVENTS_FROM_NETWORK` (default false):
   open mode refuses `?source=all` (403, code `log_feed_closed`, the switch named) and
   drops `kind: 'raw'` rows from every answer; `?source=log` still serves the parser's
   structured rows, so the debugging benefit the `BLOCKYARD_LOG_SOURCE=1` decision was
   for stays, without the verbatim log text. The gate keys off `auth.enabled`, not the
   caller's address (behind `server.trustProxy` an address check would be a fiction).
   Accounts-on deployments are unaffected.
2. `6392edf` — **Name `admin.allowWithoutAuth` in the suite's reporting (N1).** The ON
   line (boot banner + status summary, one function) now says, in that configuration:
   *accounts off, loaded via admin.allowWithoutAuth; its routes still refuse — with no
   accounts there is no admin role to grant…* — which is exactly what was measured
   against the pre-fix server (the switch satisfies the gate so the suite **loads**; the
   `viewer` ceiling still answers 403 on its routes in open mode). The status payload
   carries `allowWithoutAuth` next to `accounts`. No gate behaviour changes.
3. `30d8682` — **Pin PATH in the shipped systemd unit (N2).** One line uncommented, the
   reasoning kept beside it, a test asserting the directive is active (the commented form

4. `777e526` — **Regtest suites skip with a reason on hosts that cannot run them (N3).**

## Rollout notes

- **A (the log-feed gate):** restarting the monitor on this build changes what open
  readers see — `?source=all` on `/api/events` refuses. The UI's own event calls pass no
  `source` and are unaffected. To serve the log feed to open readers again:
  `auth.openEventsFromNetwork: true` (or `BLOCKYARD_OPEN_EVENTS_FROM_NETWORK=1`) and
  restart. The live SSE stream keeps its own pre-existing raw-chatter filter; the gate
  governs the historical endpoint the audit named.
- **C (the unit):** the installed unit is `/etc/systemd/system/blockyard.service`; apply
  the same `Environment=PATH=` line there, then `systemctl daemon-reload && systemctl
  restart blockyard`. Not part of the branch — a step on the machine.
