# The 0.1.0 announcement

For the bitcointalk thread (https://bitcointalk.org/index.php?topic=5594141): a release post for
0.1.0, the first minor release, two days after 0.0.9.

`blockyard-0.1.0-announcement.txt` is the post in Markdown; `blockyard-0.1.0-announcement.bbcode`
is the same post in BBCode for the forum. Its seven pictures (overview, block-space-mode1, mining,
explorer-tx, markets, settings, kiosk) are on talkimg.com, uploaded by the operator on
2026-09-16; the other screenshots are here too, for the thread. Every picture is a copy of `docs/images/` as shot at 0.1.0 against the local Core.

The post leads with what 0.1.0 is about: hardened defaults (loopback, sign-in, HTTPS with a
certificate made in pure Node), zero telemetry with the market feed behind an explicit switch,
the Appearance tab, the Mining dashboard, every tab on one screen, and the DOS Diversions with
the emulator's optimisation story and its measured numbers. Then a condensed changelog since
0.0.9; the full one is `CHANGELOG.md`.
